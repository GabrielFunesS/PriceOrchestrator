# PriceOrchestrator
Plataforma de gestión de precios y sincronización de catálogos orientada a entornos retail, desarrollada con .NET y PostgreSQL para explorar la evolución desde una arquitectura en capas hacia Clean Architecture y Hexagonal Architecture.

Proyecto backend desarrollado con .NET y PostgreSQL enfocado en la gestión de precios y sincronización de productos para entornos retail.

El objetivo es construir incrementalmente un sistema inspirado en escenarios reales de software enterprise, incorporando progresivamente mejoras de arquitectura, resiliencia, observabilidad y procesamiento masivo.
